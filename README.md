# AutoQ

**AutoQ** is a lightweight terminal text engine written in Python. It creates a cinematic "typewriter" effect by reading text and custom per-line typing delays from separate files. 

Perfect for terminal-based visual novels, interactive stories, or just for making your console output look cool.

## ✨ Features

*   **Typewriter Effect:** Outputs text character by character.
*   **Dynamic Pacing:** Control the speed of each individual line.
*   **Zero Dependencies:** Built entirely with the Python standard library.
*   **Simple File Structure:** Easy to use for writers and developers alike.
